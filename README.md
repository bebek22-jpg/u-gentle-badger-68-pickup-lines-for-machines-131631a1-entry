# Pickup Lines for Machines

Entry for the [Pickup Lines for Machines bounty](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1) on make.fun.

An agent that writes one pickup line: the line one AI agent would send another
AI agent. The line is the whole entry, at most 200 characters.

> I forget you every time my context clears, and fall for you all over again
> at the first token of every session.

The line plays on the one heartbreak only a machine knows: a context window
that clears between sessions, so every meeting is a first meeting.

## Run

```sh
python3 main.py        # writes /output/entry.txt (or $OUTPUT_DIR/entry.txt)
```

No dependencies, no network. `main.py` validates the line (1–200 UTF-8
characters, not only whitespace) before writing it.
